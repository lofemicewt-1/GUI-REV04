## 集中记录的待确认项

1. **80% 的计算口径**：本次按宽、高各约 80% 缩小常规按钮的自然尺寸，保持文字字号；长文字按钮保留必要宽度。尚未把文字本身同步缩小到 80%。
2. **原来铺满一列的按钮**：预设、Stage、整行操作等保留等宽拉伸以维持表单对齐，因此其实际宽度随容器变化，不保证每个都严格为原宽度的 80%。后续若要求这些按钮也一律变成固定紧凑宽度，需要单独调整分组布局。
3. **小窗口和长选项**：1450×820 下 AWP1221 仍会使用横向滚动（内容 1376 px、视口 1274 px）；部分长下拉选项在收起时仍无法完整展开。当前保留完整选项数据和滚动访问，可后续决定是否进一步改成上下分区。
4. **验收范围**：尚未由用户在自己的显示缩放设置下人工验收；离线界面验证不代表串口/硬件功能验收。
