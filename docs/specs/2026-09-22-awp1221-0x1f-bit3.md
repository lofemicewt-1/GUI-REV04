# AWP1221 0x1F bit3 Gate Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Before each listed AWP1221 user action, read register `0x1F` and if bit3 is 0, set it to 1 with a read-modify-write, once at the start of that click.

**Architecture:** Pure gate logic lives in `core/awp1221_command_gate.py` so tests do not need Tk. `AWP1221ModePage._ensure_reg_1f_bit3` wraps it with the page's 16-bit register I/O. Call it once at the start of each in-scope write path (detection/play/stop, chip-state, ROM/SINC waveform write, ADC realtime start). Do not put it inside `_write_control_command`: start-detection and waveform writes have payload I/O before the 0x02 command, and waveform writes may issue inner stop commands after the gate already ran.

**Tech Stack:** Python, unittest, existing `ctx.serial.read_register_value` / `write_register_value` (16-bit).

## Global Constraints

- Read `0x1F` (16-bit). If `(value & 0x0008) == 0`, write `value | 0x0008`. If bit3 is already 1, do not write. Preserve all other bits.
- Once per user click, not before every inner register write.
- Detection and waveform writes must gate before their first payload write, not only before the final 0x02 command.
- ADC realtime: once when starting, not on later 0x13 polls.
- Out of scope: GPIO apply, footer register read/write, ADC settings / stage apply, chip detect, caching bit3 across clicks.
- If the 0x1F read or the optional write fails, abort the user action and show the existing error dialog. Do not continue with the command.

```python
from __future__ import annotations

from collections.abc import Callable

AWP1221_CMD_GATE_REGISTER = 0x1F
AWP1221_CMD_GATE_BIT = 0x0008


def awp1221_cmd_gate_write_value(current: int) -> int | None:
    value = int(current) & 0xFFFF
    if value & AWP1221_CMD_GATE_BIT:
        return None
    return value | AWP1221_CMD_GATE_BIT


def ensure_awp1221_cmd_gate(
    read_register: Callable[[int], int],
    write_register: Callable[[int, int], None],
) -> int:
    current = int(read_register(AWP1221_CMD_GATE_REGISTER)) & 0xFFFF
    updated = awp1221_cmd_gate_write_value(current)
    if updated is None:
        return current
    write_register(AWP1221_CMD_GATE_REGISTER, updated)
    return updated
```

```python
    def _read_chip_register(self, address: int, register: int) -> int:
        resp = self.ctx.serial.read_register_value(address, register, bits=16)
        if not resp.ok:
            raise ValueError(resp.error)
        value = self.ctx.serial.extract_rdataw_value(
            resp.data,
            device_addr=address,
            reg_addr=register,
            bits=16,
        )
        if value is None:
            raise ValueError(resp.data or f"invalid register 0x{register:02X} response")
        return value

    def _write_chip_register(self, address: int, register: int, value: int) -> None:
        resp = self.ctx.serial.write_register_value(address, register, value, bits=16)
        if not resp.ok:
            raise ValueError(resp.error)
```
