# AWP1221 波形选择器：分段比例实施指南

日期：2026-09-28

## 1. 目标与适用范围

让用户决定相邻两个控制点之间分配多少采样间隔，采用百分比输入，不要求逐段填写精确点数。总比例为 100%。

- 3 个控制点形成左右两段，例如 `30%, 70%`。
- 当前默认控制点是 `0, 100, -36, 0`，形成 3 段，例如 `20%, 50%, 30%`。
- 一般情况下，M 个控制点对应 M−1 段；不能将默认的 4 个控制点误处理成两段。
- 调整比例只改变控制点沿时间轴的位置，不改变其幅值、VPK、OFFSET 或 SAMPLE_TIME。
- 适用于 Button Mode 的 RAM 波形编辑器和 Full Mode 的 SRAM 编辑器；ROM 和 SINC 的生成方式不在本次范围内。

本文件是给后续实施会话使用的指南。当前任务仅交付文档，不执行其中的改代码、测试或硬件操作步骤。

## 3. 界面方案

在“更新控制点”附近添加“各段占比（%）”区域，动态显示 M−1 行。

每行包含：`第 1 段 P0→P1`、百分比输入框和生成后的实际间隔数。最后一段为只读自动补足值，前 M−2 段可编辑。只有一段时固定显示 100%。

示例：

```text
控制点：0, 100, 0
左段 P0→P1：30.00 %
右段 P1→P2：70.00 %（自动补足）
合计：100.00 %
```

对于 4 个控制点，输入前两段 `20.00`、`50.00`，最后一段自动显示 `30.00`。所有输入最多保留两位小数；使用整数基点（100%=10000）保存，避免浮点误差导致合计为 99.999%。

操作规则：

1. 修改比例后，按 Enter 或点击“更新控制点”应用；失焦采用同一校验路径。
2. 任一段必须大于 0%，最后一段由 `10000 - 前面各段基点之和` 得出。空值、非数字、NaN、Infinity、负数、零、超过两位小数或前面各段之和达到/超过 100%均提示错误。
3. 输入中允许暂时空白，不在每个按键时弹窗；应用失败用状态文字提示，并禁止写入。
4. 更新幅值但控制点数量不变时保留比例。
5. 控制点数量改变时重建比例行，回到“均分”状态，并明确提示“控制点数量已变化，分段比例已恢复均分”。先检查幅值有效，再提交新数量和比例。
6. 提供“均分”按钮。均分使用内部等权状态，显示值按两位小数分配显示余数，使显示总和为 100.00%；显示舍入不得改变实际等权分配。编辑任一比例后转为显式比例状态，此时以各行显示值作为编辑基准。
7. 初始默认状态为均分，兼容旧波形；不要把显示的 `33.34/33.33/33.33` 当作默认内部权重。
8. 写入时所有新输入框和均分按钮一起禁用，完成或失败后恢复。现有锁定逻辑只遍历 `_sram_frame` 的直接子控件，若比例控件放在子 Frame 中，应显式登记这些控件供同一锁定/恢复流程使用。
9. 新增标签和错误同时提供中英文，延续本文件现有 `_sram_text` 方式。

建议将原“点数（auto=自动）”标签改为“起始点数（auto=自动）”，并显示“为满足压缩要求，实际点数可能增加”。比例结果旁显示实际间隔数及实际占比，帮助用户理解整数取整。

第一版只保存于当前编辑器实例；模式切换不得重置仍存活实例的比例。新建实例仍使用默认均分，不新增跨模式同步或预设文件格式。

## 4. 点数分配算法

### 4.1 分配的是间隔，公共端点只存一次

N 个采样点有 N−1 个间隔。令 `T=N-1`，分段间隔数为 `k[i]`，则：

```text
sum(k) = N - 1
k[i] >= 1
控制点采样索引 = [0, k[0], k[0]+k[1], ..., N-1]
每段包含的端点数 = k[i]+1（相邻段共享一个端点）
```

界面不要把各段的 `k[i]+1` 直接相加当作总点数。

### 4.2 最大余数法

建议新增纯函数 `allocate_segment_intervals(total_points, segment_weights)`，权重为正整数。均分传入全 1；显式比例使用基点整数，总和必须为 10000。

对每个候选 N：

1. 计算 `q[i], r[i] = divmod((N-1)*weight[i], sum(weights))`。
2. 计算 `remaining = (N-1) - sum(q)`。
3. 按余数从大到小给前 remaining 段各加 1；余数相同时按段序从前到后。
4. 若任一最终间隔数为 0，当前候选不可用。搜索下一候选，不强行将 0 改成 1，以免悄悄挪用其他段的比例。
5. 该算法每段与理想分配误差小于 1 个间隔。比例很小时可能在最大点数内仍无法满足最少一个间隔或压缩要求，应明确报错。

例：3 个控制点、比例 30/70，候选 N=102，T=101，得到 `30,71` 个间隔，控制点索引为 `0,30,101`，实际比例约为 `29.70%,70.30%`。

例：4 个控制点、比例 20/50/30，候选 N=102，得到 `20,51,30` 个间隔，索引为 `0,20,71,101`。这些只是分配例子，不代表对应任意幅值都能在 N=102 时通过压缩。

### 4.3 插值、搜索和返回结果

- 给 `generate_smooth_points` 和 `generate_waveform` 增加可选关键词参数 `segment_weights=None`；None 沿用等权行为。
- 权重数量必须等于控制点数减一；在进入搜索前校验类型、长度和正值。错误权重立即报错，不让它变成笼统的容量错误。
- 插值继续沿用当前半余弦公式。每段循环 `j=0..k[i]-1`，全曲线最后仅追加最终控制点一次。
- `generate_waveform` 每次增加 N 时都重新计算间隔、生成点列和执行压缩/解压回环验证。
- 将“候选有零间隔”与“配置非法”区分开；前者可继续搜索，后者立即退出。避免扩大现有宽泛的 ValueError 捕获而隐藏编程错误。
- 建议给 `SramWaveform` 增加 `segment_intervals` 字段，保存最终成功候选的分配；若保留外部三参数构造兼容性，可给予空元组默认值，但生成器返回值必须填充完整数据。
- 保留 SRAM 占用和连续空间检查，不能只因 words≤256 就认为可以写入。
- 失败提示建议为：“当前幅值与分段比例在 SRAM 容量内无法编码，请增大过短段的比例或减小幅值变化。”不能自动恢复均分并声称成功。

## 5. 预览、拖动与错误恢复

绘图、命中测试和状态文字统一使用同一份实际 `segment_intervals`：控制点横坐标为 `left + 累积间隔/(N-1)*width`。

- `_sram_press` 按实际控制点横坐标寻找最近点，保留当前“点击曲线附近即可选择控制点”的交互。距离相同时固定选择索引较小者。
- `_sram_drag` 继续只修改幅值；不通过水平拖动改变比例，避免本次扩大交互范围。
- 拖动可能使压缩搜索选择不同 N。重绘后更新实际边界，同时保持当前拖动的控制点索引。
- 比例合法但压缩失败时，可尝试使用 1018 点和同一比例生成仅用于编辑的预览；若该候选仍存在零间隔等问题，保留最后一次有效预览并标注“当前输入未生效”。不要在异常处理路径再次抛出未捕获错误。
- 比例输入非法时保留最后一次有效预览，清空可写结果并禁止写入。窗口缩放、主题/语言刷新或幅值拖动不得绕过无效输入而重新启用写入。
- 将幅值、比例、点数、地址校验与提交组织为同一应用流程，只有完整校验成功才更新可写结果；避免新幅值配上旧比例。
- `_start_sram_write` 重新校验当前输入，后台线程只使用捕获的不可变生成结果，不读取 Tk 变量。
- 横轴控制点跨度为 `(N-1)*SAMPLE_TIME`；当前播放时长文字使用 `N*SAMPLE_TIME`。保留现有播放时长口径并明确区分，不借本次修改推断硬件播放时序。

## 7. 必须覆盖的验证

### 核心测试

1. 未传权重时，多个 N 和控制点组合的输出与原等分算法完全一致。
2. 单段固定 100%；两段 30/70、70/30；三段 20/50/30；余数相同的稳定分配。
3. 对每份有效分配检查：间隔总和为 N−1、各段正整数、控制点索引正确、共享端点无重复、生成点列长度为 N。
4. 用可压缩的小幅值输入核对边界码值；再用默认大幅值检查自动增加 N 后仍按相同比例重新分配。
5. 显式权重长度不符、非整数、零、负值，以及 UI 非有限数输入应正确拒绝。
6. 极小比例导致候选零间隔、压缩失败、容量耗尽时返回有意义错误，不改变比例。
7. 对成功结果检查解压等于原点列、VAL2 范围、words 容量和地址边界；保留原写入协议测试。

### 离线 UI 测试与人工检查

1. 默认四控制点显示三段；改为三控制点显示左右两段；改变幅值不丢比例。
2. 输入 30/70，确认圆点位置、曲线拐点和最近点命中一致；拖动只修改被选控制点幅值。
3. 用假生成器覆盖“最终 N 大于输入 N”场景，验证 UI 采用返回的间隔元数据，而非输入 N。
4. 非法比例后连续触发缩放、主题切换、语言切换、拖动和写入，始终不产生串口写入；改正输入后可恢复。
5. 写入期间包含嵌套比例控件在内的所有输入被锁定；完成与失败后正常恢复。
6. Button Mode RAM 与 Full Mode 均可使用；切换 ROM/SINC 后可见性保持现有规则，切回保留实例内比例。
7. 使用假的串口与现有离线 Tk 测试方式，在默认尺寸、最小尺寸和缩放情况下检查控件边界、滚动到末尾可达性，保存截图与几何记录。不得连接真实端口来做 UI 验证。

## 8. 最终验收标准与回退

- 用户可以设置每一相邻控制点之间的比例，所有段合计恰为 100%；两段情形可以只填左段自动补足右段。
- 默认不设置比例时生成结果兼容旧版本。
- 实际点数增加或取整后，预览、控制点、拖动命中与写入数据一致。
- 非法输入和不可压缩形状不能写入旧结果；错误修正后正常恢复。
- 不改变 SRAM 编码、描述符、SAMPLE_TIME 寄存器语义、VPK/OFFSET、ROM/SINC 和固件。
- 有测试退出码、离线 UI 证据及明确的硬件未验证说明。

回退时只撤回本功能新增的参数、分配逻辑、比例控件及相应测试；以实施前保存的文件基线为依据，不覆盖原有未提交改动，不删除原本未跟踪的 SRAM 文件。
