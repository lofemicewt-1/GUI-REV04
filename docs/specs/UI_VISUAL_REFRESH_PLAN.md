# 软件视觉优化计划

日期：2026-09-20

本次依照用户最新要求直接实施，不使用子代理。保留开始时已有的工作区修改。

## 实施范围

1. 统一按钮圆角外侧与实际所在区域的底色，白色面板上保持白色；检查普通、按压、选中和禁用状态，以及浅色/深色主题。
2. 按钮以原有宽高的 80% 为目标，优先缩减留白、最小宽度和圆角，保持文字可读；长文字按内容保留足够宽度，避免裁切。
3. 将芯片状态按钮整理为独立、等宽、等间距的一行，避免被上方寄存器输入列撑开；整理主要工具栏和侧栏的间距。
4. 使用离线 Tk 实例测量前后尺寸、检查页面布局、主题与语言切换、按钮回调和禁用行为，并保存视觉截图。

## 验收标准

- 白色面板按钮外围没有灰色矩形底块，按压与选中效果继续有效。
- 常规按钮尺寸接近原来的 80%，长文字完整显示。
- 同组操作对齐、间隔一致，不与其他控件重叠。
- 全部已有页面能够离线构造，基础语法检查通过。
- 不操作串口、芯片寄存器、固件或板卡。

## 待集中说明项

- “80%”暂按宽和高各缩小到约 80% 理解，而非面积缩小到 80%；长文字与侧栏按内容设置必要的最小宽度。
- 现有工作区按钮图像已经包含部分底色修正，因此以本次开始时的实际源代码为基线，用户截图作为视觉目标参考。
- 更窄屏幕、高 DPI 与极端字号的实际显示需分别记录验证范围，不将离线构造等同于所有设备的人工验收。
