# AWP1221 0x1F bit3 gate before commands

Date: 2026-09-22

## Goal

Before an AWP1221 user action talks to the chip, read register `0x1F` and if bit3 is 0, set it to 1 with a read-modify-write. Do this once at the start of the click, not before every inner register write.

## Behavior

1. Read `0x1F` (16-bit).
2. If `(value & 0x0008) == 0`, write `value | 0x0008` back to `0x1F`.
3. If bit3 is already 1, do not write.
4. Preserve all other bits.

## Call sites (once each)

- Start / stop detection, start / stop play, stop all
- Chip state: reset, sleep, shutdown, default
- Waveform write (ROM and SINC), once at the start of the write
- ADC realtime window: once when starting, not on later 0x13 polls

Detection and waveform writes must gate **before** their first payload write, not only before the final 0x02 command.

## Out of scope

- GPIO apply
- Footer register read/write
- ADC settings / stage apply
- Chip detect
- Caching bit3 across clicks (every new click reads again)

## Error handling

If the 0x1F read or the optional write fails, abort the user action and show the existing error dialog. Do not continue with the command.

## Testing

Cover the helper: bit3=0 writes `value|8`; bit3=1 does not write. Cover ADC realtime so only the first poll path ensures the bit.
