# AWP1221 Full Mode 左右区域尺寸调整计划

## 用户目标
将 AWP1221 Full Mode 界面左侧区域的尺寸尽可能调整到与右侧区域一致；当前截图中左侧明显过宽。

## 执行范围
- 检查 Full Mode 页面左右区域的布局容器、列权重、最小尺寸和相关响应式逻辑。
- 以左右可用宽度接近为目标调整布局，避免只缩小左侧内容控件而不改变区域分配。
- 保留现有控件、功能、滚动行为及底部操作栏布局。
- 若窄窗口必须使用不同比例或滚动布局，沿用项目现有响应式约定。

## 验收标准
1. 常见窗口尺寸下，Full Mode 左右主区域宽度相近，左侧不再占据明显多数宽度。
2. 左侧表单可读、控件不重叠，纵向滚动仍可到达末尾；右侧波形与通信日志可正常显示。
3. 调整仅影响 AWP1221 Full Mode 的相关布局，不引入其他页面的非预期变化。
4. 执行者报告修改文件、验证方式和未覆盖的实际运行限制；不要执行硬件操作。

## 执行记录
- 用户随后明确要求不使用子智能体，由当前会话直接完成。
- 实现：Full Mode 左右两列设为相同伸缩权重和统一等宽组。
- 验证：未运行测试；本轮只检查相关布局代码及最终差异。
